## 🔧 Setup & Installation

To run this project, you need to install the required libraries. Note that **SHAP** currently requires an older version of Numpy (<2.0).

### 1. Installation
Run this command in your Jupyter Notebook:
```python
%pip install numpy<2.0
then type
%pip install shap
```
after installed, now you can import shap

### 2. Important Note

You must restart the Kernel after installation.
If you do not restart the kernel, you may see an ImportError or ValueError related to numpy.
